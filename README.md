# Atomiq

Timed PYQ practice, notes, formulae and reactions for Class 12 PCMB.

## Put it on GitHub Pages
1. Unzip this folder.
2. On github.com, create a new public repository, for example `atomiq`.
3. Click **Add file → Upload files**, drag in all the files from the unzipped folder (the files themselves, not the zip), then click **Commit changes**.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick branch `main` and folder `/ (root)`, then click **Save**.
5. After about a minute the site is live at `https://YOUR-USERNAME.github.io/atomiq/`.

## Install it like an app
- Android (Chrome): menu → Install app.
- iPhone (Safari): Share → Add to Home Screen.

## Good to know
- Registration, leaderboard and Doubt Chat need the Claude-hosted version of the site. On GitHub Pages the site runs in practice mode: exams, notes, formulae and reactions all work.
